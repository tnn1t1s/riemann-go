# riemannd

Core packages, which import the standard library and `expr-lang/expr` only: `event` (the event model and its JSON), `exprs` (the closed expression environment), `rules` (rule documents, the nine combinators, the rule store), `index` (one partition's index slice and expiry heap), `sinkqueue` (the bounded shed-newest queue whose counters close the accounting identity under one lock) and `engine` (partitions, timers, rings, the global-rule executor, admission, subscriptions, dry run, the self-observation snapshot). Adapters, which import the core and never each other: `sinks/ntfy`, `sinks/influx`, `httpapi`, `selfobs`, and `cmd/riemannd`. Start it with `go build ./cmd/riemannd && ./riemannd --listen :5555 --ntfy-url http://127.0.0.1:19090 --ntfy-topic alerts --influx-url http://127.0.0.1:8086 --influx-org o --influx-bucket b --rules rules.json`; `--shards`, `--influx-token-file` and repeatable `--set name=value` are optional, and a missing required flag exits non-zero naming it before any port is bound. The ring, the index and all rule state are in memory and lost on restart. No tests are included, so the I8 import-graph check is not carried in the tree; `go list -deps` over the core packages shows no adapter.

Decisions marked `SPEC-GAP`, grouped (36 notes; `grep -rn 'SPEC-GAP:' --include='*.go' .` lists them):

- Clock: timers and expiries fire when the wall clock reaches them, and also ahead of any event stamped later than them; `now` is the wall clock. A dry run uses the replayed events' own times and leaves timers pending after the last event unfired.
- Absent `metric`: reads as nil in an expression (`metric == nil` tests it); ordering or arithmetic on it is an evaluation error, which makes a `where` discard and count the event, a `match` not match, and a `splitp` branch not hold. Elements of `events` read the same way. `by`/`stable` on `metric` give all metric-less events one key.
- `set`: null on `metric` removes the metric, null elsewhere gives the schema default; an empty `host` or `service` after a `set` discards the event with a count.
- `by` fork freeing is applied mechanically to any event with state `expired`, for any `fields`, client-sent included. `by` and `stable` accept `attributes.<key>`.
- Two `changed-state` nodes on one path: the one nearest the sink supplies `prior_state`. `initial` and `children` may be omitted. A `splitp` threshold may be a number, string or boolean.
- Rules: canonical form is sorted-key JSON without `version` and with `enabled` and `partition` defaulted; an `id` absent from the body or differing from the path is a 400; rules evaluate in ascending id order.
- Ingest: an empty `host` or `service` counts as absent; unknown event keys are ignored; zero and negative `ttl` are accepted as sent.
- Reads: `since` filters on event `time`, `limit` defaults to 1000 and keeps the most recent; SSE events are unnamed `data:` frames and a lagged frame carries `{"count":n}`; dry-run firings use the keys `sink`, `event`, `node`.
- Self-observation: queue names `sink.ntfy`, `sink.influx`, `shard.inbox`, `subscribe`, `stable.buffer`; `riemann.rule.discarded` attributes are `rule`, `version`, `node`; fork counters are `riemann.rule.forks_live` and `riemann.rule.forks_freed`; events carry the machine hostname and state `ok`, so readings that share a service share an identity and differ only by attributes. `/metrics` names are the service names with `.` replaced by `_` and attributes as labels.
- Sinks: a failed delivery is not retried and counts as dropped; the human alert line shows `null` for an absent metric; a NaN or infinite metric is not written to influx; attributes that are empty or named `host`/`state` are left out of the line.
- Configuration: `--set` values are plain numbers in SCALE.md's units and must be positive; `--shards` disagreeing with `--set engine.shards` is fatal; `ingest.max_inflight_requests` bounds accepted connections.
