# riemannd

The core packages are `internal/config` (the `SCALE.md` parameters and the `--set` parser), `internal/event` (the event model and its JSON form), `internal/expression` (the wrapper over `github.com/expr-lang/expr`), `internal/rule` (rule documents, the compiler and the nine combinators) and `internal/engine` (partitions, inboxes, index, ring, timers, subscriptions, the snapshot); the adapters are `internal/httpapi`, `internal/selfobs`, `internal/sink/ntfy` and `internal/sink/influx`, and `cmd/riemannd` wires them together. Start it with `go build -o riemannd ./cmd/riemannd` and then `./riemannd --listen :5558 --ntfy-url http://127.0.0.1:19090 --ntfy-topic alerts --influx-url http://127.0.0.1:8086 --influx-org o --influx-bucket b --rules rules.json`, adding `--shards`, `--set name=value` and `--influx-token-file` as needed; all state, the ring and rules put over HTTP included, is held in memory and lost on restart. Each decision the spec left open is marked `SPEC-GAP` at the code that makes it, and `grep -rn SPEC-GAP .` lists all of them. The ones that change observable behavior: the engine clock is the later of the wall clock and the latest event time dispatched; `metric` on an event without one reads as nil, and an expression that fails at evaluation does not hold; a subscription carries index changes (index-leaf inserts and expiries), live events as unnamed SSE frames, snapshot entries as `event: snapshot`, and `lagged` as `{"count":n}`; `since` on `GET /events` is inclusive and `limit` defaults to 1000; an absent `q` selects everything; error bodies are `{"error":"..."}` and `/healthz` answers `{"status":"ok"}`; dry-run firings use the keys `sink`, `event` and `node`; `/metrics` names are the self-observation service names with dots replaced by underscores; self-observation events carry the machine's hostname as `host`, state `ok`, and the attribute keys `shard`, `rule`, `version` and `node`, with the added services `riemann.rule.passed`, `riemann.by.forks_live`, `riemann.by.forks_freed`, `riemann.ingest.inflight_requests` and `riemann.ingest.rejected_batches`; the admission deadline is per request; `ingest.max_inflight_requests` bounds open connections; both sinks send once with no retry, counting an answered request as processed and an unanswered one as dropped; the influx sink writes whatever is queued, up to 500 lines per request, and counts an event with no metric as dropped; bindings referenced more than once share one state; rule versions continue after a `DELETE`; unknown rule document keys are kept and hashed; `by` and `stable` accept `attributes.<key>` as a field name; a `set` expression that yields null restores the field's default, and one that empties `host` or `service` discards the event; an empty `host` or `service` at ingest is `400`; a flag given an empty value counts as missing, `--shards` disagreeing with `--set engine.shards` is fatal, and an empty token file is fatal.
