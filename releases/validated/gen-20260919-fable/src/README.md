# riemannd

Core packages, which import the standard library and `github.com/expr-lang/expr` only: `event` (the event model and ingest validation), `exprs` (the closed expression name domain), `rule` (rule documents, the compiler, the nine combinators), `index` (one partition's index slice and its expiry deadlines), `engine` (the clock, partition loops, timers, rings, the rule registry, the global-rule executor, dry run, and the snapshot), and `boundedq` (the shed-newest queue with exact accounting). Adapters, which import the core and never each other: `sinks/ntfy`, `sinks/influx`, `httpapi`, `promtext` (`GET /metrics`) and `selfobs` (the self-observation sampler); `cmd/riemannd` wires them. Start it with `go build -o riemannd ./cmd/riemannd && ./riemannd --listen :5580 --ntfy-url <url> --ntfy-topic <topic> --influx-url <url> --influx-org <org> --influx-bucket <bucket> --rules rules.json [--shards N] [--set name=value]...`; every flag but the last two is required, and a missing one is fatal before any port is bound. The ring and all stream state are in memory and are lost on restart. Decisions marked `// SPEC-GAP:` in the source (`grep -rn SPEC-GAP .`): the engine clock is the wall clock plus a forward-only offset moved by future-stamped events, and receive time is read from it (`engine/clock.go`); an expression referencing `metric` does not hold for an event without one, and `events[i].metric` reads 0 when absent (`exprs`); `set` results that are null, mistyped, non-finite or leave an empty identity, and expressions that fail at evaluation (`rule/runtime.go`); which events free a `by` fork, which `by` nodes free at all, and what a new event does to a fork awaiting a timer (`rule/runtime.go`); `attributes.<key>` as a `by` or `stable` field, an absent `metric` in a fork key, an absent `initial`, an absent `children`, unreferenced bindings, and `host,service` running exactly as `host` (`rule/compile.go`); the canonical form behind the content hash and a PUT body with no `id` (`rule/doc.go`); rule evaluation order (`engine/engine.go`); what `/subscribe` streams, what its snapshot holds and its frame format (`engine/engine.go`, `httpapi/subscribe.go`); the dry-run clock, and dry run ignoring `enabled` and `expires_at` (`engine/dryrun.go`); expiry events entering the ring (`engine/shard.go`); unknown event keys, wrong-typed fields, zero or negative `ttl`, and which fields the read surface writes (`event`); an absent `q`, and the meaning of `since` and `limit` (`httpapi`); metric names at `/metrics` (`promtext`); the host, the shared identity of per-partition series, and the `riemann.rule.passed` name in self-observation (`selfobs`); the human-line rendering of an absent metric and at-most-once delivery with no retry (`sinks/ntfy`); tag order and empty attribute values in line protocol (`sinks/influx`); and rules not being written back to `--rules` (`cmd/riemannd`). `INVARIANTS.md` I8 asks a generation to carry its own import-graph test; none is here because the generation brief forbids tests, so that check is `go list -deps` run by hand.
